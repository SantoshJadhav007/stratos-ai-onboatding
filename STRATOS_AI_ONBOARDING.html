🚀 Stratos AI Platform

Complete Integration & Onboarding Guide

📋 Platform Overview

Stratos AI is a comprehensive platform for managing AI agents, monitoring their performance, tracking costs, and ingesting telemetry data. This guide walks you through the complete integration process.

🔐 Authentication

Secure token-based authentication using Supabase. Each request requires a valid JWT token.

🤖 Agent Management

Create and manage AI agents with custom configurations, budgets, and model preferences.

📊 Monitoring & Metrics

Real-time monitoring of agent performance with detailed metrics and usage tracking.

💰 Budget Control

Set and enforce spending limits per agent with flexible allocation strategies.

📡 Telemetry Ingestion

OpenTelemetry-compatible data ingestion for comprehensive observability.

🏢 Organization Units

Hierarchical organization structure for managing agents across teams and departments.

🎯 Key Concepts

Access Token (JWT)

A JSON Web Token obtained after authentication. Used to authorize all subsequent API requests. Tokens have an expiration time and should be refreshed as needed.

Organization Units

Hierarchical containers for organizing agents. Supports nested structure for multi-team environments. Each agent must belong to an organization unit.

Enroll Token

A temporary token provided by the platform to SDK/agent instances. Used for heartbeat and telemetry ingestion without requiring full authentication.

Telemetry

OpenTelemetry-formatted span data including execution traces, token usage, model information, and performance metrics.

🔐 Understanding Token Types

🎯 Two Different Tokens

Access Token (JWT): From Supabase auth. Used for management APIs (creating agents, getting metrics, etc.)
Enroll Token: From agent creation. Used by agents for heartbeat and telemetry ingestion. Short-lived, agent-specific.
Rule: Never confuse them! Using wrong token will result in 401 errors.

Access Token

  • From: Supabase /auth/v1/token
  • Used by: Control plane / Dashboard
  • Header: Authorization: Bearer
  • Expires: ~3600 seconds
  • APIs: Agent mgmt, metrics, budgets

Enroll Token

  • From: Agent creation response
  • Used by: Agent / SDK
  • Header: x-stratos-token
  • Expires: Long-lived
  • APIs: Heartbeat, telemetry

🔑 Getting Your Access Token

⚠️ Security Note

Never commit credentials to version control. Use environment variables and .gitignore files.

Obtain JWT Token

Exchange your credentials for an access token: 

curl -X POST "https://your-project.supabase.co/auth/v1/token?grant_type=password" \
  -H "Content-Type: application/json" \
  -H "apikey: your-supabase-anon-key" \
  -d '{
    "email": "your-email@example.com",
    "password": "your-password"
  }'

Response will contain your access token: 

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 3600,
  "refresh_token": "..."
}

Python Integration

import requests
import json
from datetime import datetime, timezone

class StratosAgent:
    def __init__(self, base_url: str, enroll_token: str):
        self.base_url = base_url
        self.enroll_token = enroll_token
        self.session = requests.Session()
        self.session.headers.update({
            'x-stratos-token': enroll_token,
            'Content-Type': 'application/json'
        })

    def send_heartbeat(self, framework: str, model: str):
        """Send periodic heartbeat to mark agent as active."""
        response = self.session.post(
            f"{self.base_url}/api/heartbeat",
            json={
                "framework": framework,
                "model": model
            }
        )
        return response.json()

    def ingest_telemetry(self, service_name: str, spans: list):
        """Ingest OpenTelemetry formatted spans."""
        payload = {
            "resourceSpans": [{
                "resource": {
                    "attributes": [{
                        "key": "service.name",
                        "value": {"stringValue": service_name}
                    }]
                },
                "scopeSpans": [{
                    "scope": {"name": "opentelemetry.instrumentation.langchain"},
                    "spans": spans
                }]
            }]
        }
        response = self.session.post(
            f"{self.base_url}/api/ingest",
            json=payload
        )
        return response.json()

JavaScript/Node.js Integration

import axios from 'axios';

class StratosAgent {
  constructor(baseUrl, enrollToken) {
    this.baseUrl = baseUrl;
    this.enrollToken = enrollToken;
    this.client = axios.create({
      baseURL: baseUrl,
      headers: {
        'x-stratos-token': enrollToken,
        'Content-Type': 'application/json'
      }
    });
  }

  async sendHeartbeat(framework, model) {
    try {
      const response = await this.client.post('/api/heartbeat', {
        framework,
        model
      });
      return response.data;
    } catch (error) {
      console.error('Heartbeat failed:', error.message);
      throw error;
    }
  }

  async ingestTelemetry(serviceName, spans) {
    try {
      const payload = {
        resourceSpans: [{
          resource: {
            attributes: [{
              key: 'service.name',
              value: { stringValue: serviceName }
            }]
          },
          scopeSpans: [{
            scope: { name: 'opentelemetry.instrumentation.langchain' },
            spans
          }]
        }]
      };
      const response = await this.client.post('/api/ingest', payload);
      return response.data;
    } catch (error) {
      console.error('Telemetry ingestion failed:', error.message);
      throw error;
    }
  }
}

Go Integration

package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"time"
)

type StratosAgent struct {
	baseURL    string
	enrollToken string
	client     *http.Client
}

func NewStratosAgent(baseURL, enrollToken string) *StratosAgent {
	return &StratosAgent{
		baseURL:    baseURL,
		enrollToken: enrollToken,
		client:     &http.Client{Timeout: 10 * time.Second},
	}
}

func (a *StratosAgent) SendHeartbeat(framework, model string) error {
	payload := map[string]string{
		"framework": framework,
		"model":     model,
	}
	body, _ := json.Marshal(payload)

	req, _ := http.NewRequest("POST", a.baseURL+"/api/heartbeat",
		bytes.NewBuffer(body))
	req.Header.Set("x-stratos-token", a.enrollToken)
	req.Header.Set("Content-Type", "application/json")

	resp, err := a.client.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		body, _ := io.ReadAll(resp.Body)
		return fmt.Errorf("heartbeat failed: %s", body)
	}
	return nil
}

func (a *StratosAgent) IngestTelemetry(serviceName string,
	spans []map[string]interface{}) error {
	payload := map[string]interface{}{
		"resourceSpans": []map[string]interface{}{
			{
				"resource": map[string]interface{}{
					"attributes": []map[string]interface{}{
						{
							"key": "service.name",
							"value": map[string]string{"stringValue": serviceName},
						},
					},
				},
				"scopeSpans": []map[string]interface{}{
					{
						"scope": map[string]string{
							"name": "opentelemetry.instrumentation.langchain",
						},
						"spans": spans,
					},
				},
			},
		},
	}
	body, _ := json.Marshal(payload)

	req, _ := http.NewRequest("POST", a.baseURL+"/api/ingest",
		bytes.NewBuffer(body))
	req.Header.Set("x-stratos-token", a.enrollToken)
	req.Header.Set("Content-Type", "application/json")

	resp, err := a.client.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		body, _ := io.ReadAll(resp.Body)
		return fmt.Errorf("ingest failed: %s", body)
	}
	return nil
}

⭐ Best Practices & Real-World Insights

💡 Agent Lifecycle

Pending: Created but not active. No execution data yet.
Online: Agent is running and sending heartbeats. Execution data available.
Agent transitions from pending to online when first heartbeat is received.

🔐 Authentication

  • Always use HTTPS in production
  • Rotate tokens regularly
  • Store credentials in secure vaults
  • Never commit tokens to version control

📡 Heartbeat Management

  • Send heartbeat every 5-10 minutes
  • Implement exponential backoff for retries
  • Monitor heartbeat failures
  • Log all heartbeat attempts

📊 Telemetry

  • Use OpenTelemetry standard format
  • Include all relevant context (model, framework)
  • Batch telemetry when possible
  • Validate data before sending

💰 Budget Management

  • Set conservative initial budgets
  • Monitor spending closely
  • Use enforcement flags for hard limits
  • Review budget allocation monthly

⚠️ Error Handling

  • Implement retry logic with backoff
  • Log all errors with context
  • Handle network timeouts gracefully
  • Alert on repeated failures

📈 Monitoring

  • Track API response times
  • Monitor token usage trends
  • Set up cost alerts
  • Use metrics for optimization

Implement automatic token refresh before expiration: 

const refreshToken = async () => {
  const expiresAt = Date.parse(tokenExpiry);
  const now = Date.now();
  const refreshThreshold = 5 * 60 * 1000; // 5 minutes

  if (expiresAt - now < refreshThreshold) {
    // Token expires soon, refresh it
    const newToken = await authenticateUser();
    saveToken(newToken);
  }
};

// Check every minute
setInterval(refreshToken, 60000);

Retry with Exponential Backoff

Handle transient failures gracefully: 

async function retryWithBackoff(
  fn,
  maxRetries = 3,
  initialDelay = 1000
) {
  let lastError;

  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
      const delay = initialDelay * Math.pow(2, i);
      console.warn(
        `Attempt ${i + 1} failed, retrying in ${delay}ms...`,
        error.message
      );
      await new Promise(resolve => setTimeout(resolve, delay));
    }
  }

  throw lastError;
}

// Usage
await retryWithBackoff(
  () => agent.sendHeartbeat('langchain', 'gpt-4o')
);

Telemetry Batching

Batch multiple spans for efficient transmission: 

class TelemetryBuffer {
  constructor(agent, batchSize = 10, flushInterval = 30000) {
    this.agent = agent;
    this.spans = [];
    this.batchSize = batchSize;
    this.flushInterval = flushInterval;
    this.startFlushTimer();
  }

  addSpan(span) {
    this.spans.push(span);
    if (this.spans.length >= this.batchSize) {
      this.flush();
    }
  }

  async flush() {
    if (this.spans.length === 0) return;

    const spansToSend = this.spans.splice(0);
    try {
      await this.agent.ingestTelemetry('agent-name', spansToSend);
      console.log(`Flushed ${spansToSend.length} spans`);
    } catch (error) {
      console.error('Flush failed:', error);
      // Re-add spans to buffer for retry
      this.spans.unshift(...spansToSend);
    }
  }

  startFlushTimer() {
    setInterval(() => this.flush(), this.flushInterval);
  }
}

🔧 Troubleshooting Guide

❌ 401 Unauthorized

Cause: Invalid or expired token

  • Verify token is not expired
  • Check token is correctly formatted (Bearer token)
  • Re-authenticate to get a new token
  • Verify Authorization header is set correctly

❌ 400 Bad Request

Cause: Malformed request body or missing required fields

  • Validate JSON syntax
  • Check all required fields are present
  • Verify field data types match schema
  • Check Content-Type header is application/json

❌ 404 Not Found

Cause: Agent or resource doesn't exist

  • Verify agent ID is correct and exists
  • Check API endpoint URL is correct
  • Verify org_unit_id exists and is accessible
  • Ensure agent has been fully created (not still pending)

❌ 500 Internal Server Error

Cause: Server-side issue

  • Check service status and logs
  • Retry request with exponential backoff
  • Contact support with request ID
  • Check for service maintenance announcements

⚠️ Agent Stuck in Pending

Issue: Agent shows "pending" status, not transitioning to "online"

  • Install the Stratos SDK from the enroll response
  • Set STRATOS_TOKEN from the enroll token (NOT access_token)
  • Restart agent with SDK import/flag
  • First heartbeat will transition it to online
  • Verify server is running: curl http://localhost:5012/api/health

⚠️ High Latency

Issue: API responses are slow

  • Check network connectivity
  • Verify API endpoint is healthy (health check)
  • Check for rate limiting headers
  • Monitor server resource usage

📋 Debug Checklist

  1. Connectivity - Can you reach the API? 
    curl -v http://localhost:5012/api/health
  2. Authentication - Is your token valid? 
    curl -X GET http://localhost:5012/api/me \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -v
  3. Agent Status - What's the actual status? 
    curl -X GET http://localhost:5012/api/agents/AGENT_ID \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -v
  4. Response Headers - Check response metadata 
    curl -i -X GET http://localhost:5012/api/health
  5. Request/Response Logging - Enable detailed logging 
    DEBUG=* node your-script.js
